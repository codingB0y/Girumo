## 1. FlowCore — Social Media Automation
**Link:** behance.net/gallery/245958151
**Nicho:** Automação de workflows / AI agents

### Estilo
- Dark mode como base
- Nodes conectados + linhas de fluxo
- UI-inspired layouts (cards, dashboards simulados)
- Gradientes neon como acento
- Sans-serif moderna, hierarquia forte

### O que funciona
- Conceitos complexos traduzidos em visuais simples
- Cada peça = 1 conceito (workflow, scalability, orchestration)
- Mockups de interface como prova de produto

### Aplicável ao HubFlow
- ✅ Dark mode (nosso Breu #0B0D1A já é isso)
- ✅ Conceito de "fluxo" visual (combina com nosso símbolo de elos)
- ✅ Cards de UI mostrando o painel real
- ⚠️ Evitar excesso de nodes/linhas — nosso visual é mais limpo

## 2. CrimsonEdge — Prop Firm Trading
**Link:** behance.net/gallery/244353197
**Nicho:** Fintech / Trading / Prop Firm

### Estilo
- Dark premium total
- Acento em vermelho carmesim
- Headlines ultra-bold, sans-serif
- Dados numéricos estilizados (grafismos de performance)
- Linguagem visual de terminal/dashboard

### O que funciona
- Percepção de valor altíssima pelo dark + dados
- Números como protagonistas visuais
- Posicionamento premium sem texto demais

### Aplicável ao HubFlow
- ✅ Dados/métricas como elemento visual central (R$47k, +200%, etc.)
- ✅ Dark premium com acento forte (nosso Íris no lugar do carmesim)
- ✅ Headlines bold (Bricolage Grotesque 800 faz isso)
- ⚠️ Não usar estética de trading — nosso público é lojista, não trader

## 3. Halo — Software AI Social Media
**Link:** behance.net/gallery/249801303
**Nicho:** AI SaaS / Produtividade

### Estilo
- **Light mode** como diferenciador (anti-tendência)
- Paleta suave: lavender, peach, mint
- Minimalismo silencioso — muito whitespace
- Tipografia display como elemento principal
- Elementos 3D sutis (pontuação, não decoração)
- Logo propositalmente pequeno

### O que funciona
- Narrativa temporal: cada peça é um momento do dia ("8:40am", "a 127ª aba")
- Copy de identificação imediata com a dor
- Anti-tendência: enquanto todos são dark/neon, Halo é claro/suave
- Marca que sussurra em vez de gritar

### Aplicável ao HubFlow
- ✅ Copy ancorada em momentos reais do lojista ("A 53ª mensagem sem resposta")
- ✅ Tipografia como protagonista (Bricolage Grotesque grande)
- ✅ Whitespace como respiro — usar na versão Bruma (fundo claro)
- ✅ Micro-narrativas do cotidiano do comércio
- ⚠️ Nosso dark (Breu) é a base — usar light só na composição-mãe #3 (Bruma)

## Fórmulas de gancho (extraídas dos benchmarks)

1. **Momento temporal:** "São 23h47 e você ainda tá respondendo grupo." (Halo)
2. **Dado impactante:** "R$47k. 1 painel. 3 grupos." (CrimsonEdge)
3. **Conceito simplificado:** "Antes: caos. Depois: fluxo." (FlowCore)
4. **Dor específica:** "A 53ª mensagem sem resposta hoje." (Halo)
5. **Contraste visual:** Dark com número grande em Íris (CrimsonEdge + nosso)
