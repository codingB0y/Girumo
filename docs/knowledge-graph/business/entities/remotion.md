# Remotion

**Type:** artifact

Remotion is a software framework and library designed for programmatic video creation and rendering using React. It functions as a comprehensive tool for mixing audio and video elements, incorporating specific audio components and frame controls to build media compositions. Remotion has been utilized in specialized applications, such as the Girumo film renderer, and has been associated with version 4.0.489. Additionally, Remotion operates as a technology provider connected with a license classification system used in the video rendering domain.
