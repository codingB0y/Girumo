# Dashboard

**Type:** artifact

Dashboard serves as the primary interface screen and central digital tool component for users, specifically within the HubFlow platform, where it is currently utilized to display simulated data. As the core page of the application, it provides a comprehensive visual interface designed to facilitate the monitoring of business activities, growth metrics, and general platform performance.

For merchants and shopkeepers, the Dashboard functions as an essential command center for tracking business health and interacting with the product. Beyond simple data visualization, the interface is engineered to enable users to manage groups effectively and perform quick actions, ensuring that critical information and functional tools are easily accessible within a single, cohesive view.<SEP>The main visual interface providing an overview of performance and key data for users.
