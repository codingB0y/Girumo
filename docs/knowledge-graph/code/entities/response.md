# Response

**Type:** artifact

Response is a standard web API interface and digital object utilized to convey the outcome of client requests. It functions as an outgoing HTTP response object generated by a system or route to communicate the results of a transaction back to the client.

As a versatile interface, the Response object is primarily responsible for constructing and returning JSON-formatted data, such as group claim information or cancelled message details. In addition to delivering successful data payloads, it serves as the mechanism for reporting error statuses and system messages.
