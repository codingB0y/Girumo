# Logo

**Type:** artifact

Logo is a React component and visual representation of the HubFlow brand used throughout the application interface. It functions as a horizontal brand lockup that combines the LogoSymbol with the text wordmark. 

The Logo component is utilized extensively across various navigation and layout sections of the application, serving as the primary brand identifier.
