# Docker

**Type:** artifact

Docker is a comprehensive platform designed for developing, shipping, and running applications inside containers, featuring hardened security configurations. As a versatile containerization technology and tool, Docker is widely utilized for application deployment and deployment preparation. 

In specific operational contexts, Docker is employed as the containerization platform used for building and deploying the Hubflow-Engine. Furthermore, it serves as the containerization technology used on Virtual Private Servers (VPS) in conjunction with Coolify, specifically utilized for engine deployment on VPS environments. Additionally, Docker can be configured as a containerization tool with root access, no limits, and an orphaned sessions volume.<SEP>A containerization runtime and tool using Alpine images for the engine.<SEP>A containerization tool and runtime used for building and running images with a pinned Node runtime.<SEP>The containerization platform used for building the engine.
