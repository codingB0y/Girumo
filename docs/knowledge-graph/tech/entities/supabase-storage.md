# Supabase Storage

**Type:** artifact

Supabase Storage is a cloud storage service provided by Supabase, serving as an integral component of the final technology stack for file, data object, and media management. Designed as a private storage service, it is utilized to securely store private media uploads and manage various files and data objects. 

Supabase Storage is specifically used to manage storage buckets and individual files, such as an application's uploads bucket. Additionally, the service is equipped to handle user file uploads while enforcing specific storage limits that vary depending on the user's subscription plan.
