# Baileys

**Type:** artifact

Baileys is a specialized software library integrated into the Hubflow-Engine to facilitate essential messaging and communication functionalities. It serves as a core module utilized by the engine to execute specific functional operations, particularly those related to WhatsApp automation and integration. Within the HubFlow ecosystem, Baileys is employed to perform complex WhatsApp-related commands and communication processes, which are typically invoked via explicit import within the application's engine.

In addition to its role in messaging, Baileys functions as a critical tool for session management. Due to the sensitive nature of these operations, the library requires strict adherence to security versioning protocols. Furthermore, it is a operational requirement that any session data managed by Baileys, particularly regarding WhatsApp web automation, must never be committed to Git repositories to prevent potential security vulnerabilities and unauthorized access to session information.
