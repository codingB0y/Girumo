# Starter

**Type:** concept

Starter is a service plan and entry-level sales machine implementation tier designed for stores with a monthly revenue ranging from R$30,000 to R$60,000. Priced at R$3,497, this plan features a 21-day implementation timeline and serves as a lateral or alternative plan option within the pricing structure, appearing visually secondary on mobile devices. 

As a basic sales machine package, the Starter plan includes essential processes and creative editing utilizing existing materials, though it is specifically provided as a service tier without video recording. Additionally, it functions as a secondary plan option used in alternative revenue and client mix scenarios.
