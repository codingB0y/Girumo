# HubFlow — Templates de Posts para Redes Sociais

> Guia prático com modelos de posts prontos para Instagram, LinkedIn, Stories e WhatsApp Status.
> Adapte os textos mantendo o tom: direto, coloquial, orientado a resultado.

---

## Paleta e diretrizes visuais para posts

| Elemento | Valor | Uso |
|----------|-------|-----|
| Fundo principal | `#0B0D1A` (breu) | Background de carrosséis e banners |
| Acento / CTA | `#6A4BF0` (iris) | Botões, destaques, ícones |
| Acento hover | `#8A6CFF` (iris claro) | Gradientes, brilhos |
| Texto claro | `#ECEBF5` (bruma) | Texto sobre fundo escuro |
| Verde WhatsApp | `#25D366` | Ícone do WhatsApp, badges de sucesso |
| Fonte títulos | Bricolage Grotesque (Bold/ExtraBold) | Headlines |
| Fonte corpo | IBM Plex Sans | Textos corridos |
| Fonte dados | IBM Plex Mono | Números, métricas, labels |

**Regras visuais:**
- Fundo escuro (breu) com gradiente iris sutil = premium
- Nunca usar fundo branco puro — a marca é dark-first
- Screenshots do painel real > mockups genéricos
- Logo: símbolo (elos) em iris + wordmark em branco
